# Plugin scope register

The CSV is an original reusable brief template. It describes acceptance and ownership fields without including a proprietary plugin or client configuration. Copy it into an authorised private project workspace.

For a supplier import, define stable product identifiers, authoritative fields, validation, staged differences and who may approve them. Record background scheduling, retries, duplicate detection and how accepted changes can be reconciled. An AI classification suggestion is a separate input from the business's publication decision.

Do not store credentials, order exports or private customer URLs in the public register. The purpose is to make the workflow reviewable before code is commissioned. Pair the template with the [plugin-scoping checklist](../docs/custom-plugin-development.md) and [WooCommerce compatibility checklist](../docs/woocommerce-engineering.md).
